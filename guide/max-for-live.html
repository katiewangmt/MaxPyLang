Max for Live

Tip

To try this without installing anything, the Plugin generator builds a Max for Live audio effect in your browser and downloads the .amxd.

A Max for Live device is a patch in a .amxd file that runs inside Ableton Live. Build it like any patch, then save it with a device_type:

patch.save("synth.amxd", device_type="instrument")

device_type

Goes on

Input objects

Output objects

"instrument"

a MIDI track

midiin → midiparse, or notein

plugout~

"audio_effect"

an audio track, after a device

plugin~

plugout~

"midi_effect"

a MIDI track, before an instrument

midiin → midiparse

midiformat → midiout

  • Setting device_type always writes .amxd; save("synth", device_type="instrument") writes synth.amxd.

  • Saving a .amxd name without device_type raises ValueError.

  • mp.MaxPatch(load_file="device.amxd") loads a device to edit, if it was saved unfrozen and has no UI objects; see Known issues.

Live’s I/O, not Max’s

In a device, audio comes from and goes to Live’s track, not the sound card:

In a device

Why

ezdac~, dac~

plugout~

Output goes to the track’s mixer

adc~, ezadc~

plugin~

Input comes from the track

a toggle on ezdac~

nothing

Live runs audio; the device is always on

plugin~ has two outlets and plugout~ two inlets: left and right. Connect both for stereo.

A clip~ -1. 1. before plugout~ is an optional safety net while you experiment: it stops a mistake from sending very loud audio to Live. Cycling ‘74’s own devices do not use one.

Note

Use Live’s own interface objects for a device’s controls (live.dial, live.slider, live.numbox, live.toggle, live.gain~, …): Live can show, save and automate them. They are stubs in maxpylang.objects: from maxpylang.objects import live_dial. In this site’s browser player only live.dial and live.gain~ are interactive; the others work in Max.

Instrument

"""Max for Live instrument: MIDI note in, sine tone out."""
import maxpylang as mp
from maxpylang.objects import clip_tilde, cycle_tilde, mtof, notein, plugout_tilde

patch = mp.MaxPatch(verbose=False)

patch.set_position(30, 30)
note = patch.place(notein)[0]          # outlets: pitch, velocity, channel
patch.set_position(30, 90)
freq = patch.place(mtof)[0]            # MIDI pitch -> frequency in Hz
patch.set_position(30, 150)
osc = patch.place(cycle_tilde)[0]
patch.set_position(30, 210)
level = patch.place("*~ 0.2")[0]       # quieter
patch.set_position(30, 270)
safe = patch.place(clip_tilde(-1.0, 1.0))[0]  # keep the output between -1 and 1
patch.set_position(30, 330)
out = patch.place(plugout_tilde)[0]    # to Live; inlets 0 and 1 are left and right

patch.connect(
    (note.outs[0], freq.ins[0]),
    (freq.outs[0], osc.ins[0]),
    (osc.outs[0], level.ins[0]),
    (level.outs[0], safe.ins[0]),
    (safe.outs[0], out.ins[0]),
    (safe.outs[0], out.ins[1]),
)

patch.save("sine_instrument.amxd", device_type="instrument")

# .amxd files load like .maxpat files.
device = mp.MaxPatch(load_file="sine_instrument.amxd", verbose=False)
print(device.num_objs, "objects")

Audio effect

"""Max for Live audio effect: a tremolo on both channels."""
import maxpylang as mp
from maxpylang.objects import clip_tilde, cycle_tilde, plugin_tilde, plugout_tilde

patch = mp.MaxPatch(verbose=False)

patch.set_position(30, 30)
src = patch.place(plugin_tilde)[0]    # from Live; outlets 0 and 1 are left and right

# LFO: cycle~ swings -1..1; scale it to 0..1 for a volume control.
patch.set_position(200, 30)
lfo = patch.place(cycle_tilde(4))[0]
patch.set_position(200, 90)
half = patch.place("*~ 0.5")[0]
patch.set_position(200, 150)
offset = patch.place("+~ 0.5")[0]

patch.set_position(30, 210)
left, right = patch.place("*~", num_objs=2, spacing=[80, 0])
patch.set_position(30, 270)
safe_l, safe_r = patch.place(clip_tilde(-1.0, 1.0), num_objs=2, spacing=[80, 0])
patch.set_position(30, 330)
out = patch.place(plugout_tilde)[0]

patch.connect(
    (lfo.outs[0], half.ins[0]),
    (half.outs[0], offset.ins[0]),
    (src.outs[0], left.ins[0]),
    (src.outs[1], right.ins[0]),
    (offset.outs[0], left.ins[1]),     # audio into the right inlet of *~ sets the gain
    (offset.outs[0], right.ins[1]),
    (left.outs[0], safe_l.ins[0]),
    (right.outs[0], safe_r.ins[0]),
)
patch.connect((safe_l.outs[0], out.ins[0]), (safe_r.outs[0], out.ins[1]))

patch.save("tremolo.amxd", device_type="audio_effect")

MIDI effect

midiparse splits raw MIDI by kind, one outlet each, and midiformat builds MIDI from the same kinds, one inlet each, in nearly the same order. The first of each carries notes as a two-item list, pitch then velocity; the second is poly key pressure, not velocity. So to change notes, unpack the list, change it, and pack it again before midiformat:

"""Max for Live MIDI effect: transpose every note up 7 semitones."""
import maxpylang as mp
from maxpylang.objects import midiformat, midiin, midiout, midiparse

patch = mp.MaxPatch(verbose=False)

patch.set_position(30, 30)
src = patch.place(midiin)[0]           # raw MIDI from the track
patch.set_position(30, 90)
parse = patch.place(midiparse)[0]      # outlet 0: notes, as a list (pitch, velocity)
patch.set_position(30, 150)
split = patch.place("unpack 0 0")[0]   # sends velocity (right) first, then pitch (left)
patch.set_position(30, 210)
up = patch.place("+ 7")[0]
patch.set_position(30, 270)
join = patch.place("pack 0 0")[0]      # velocity waits in the right inlet; pitch sends the pair
patch.set_position(30, 330)
fmt = patch.place(midiformat)[0]       # inlet 0: notes, as a list (pitch, velocity)
patch.set_position(30, 390)
out = patch.place(midiout)[0]          # to the next device on the track

patch.connect(
    (src.outs[0], parse.ins[0]),
    (parse.outs[0], split.ins[0]),
    (split.outs[0], up.ins[0]),
    (split.outs[1], join.ins[1]),
    (up.outs[0], join.ins[0]),
    (join.outs[0], fmt.ins[0]),
    (fmt.outs[0], out.ins[0]),
)

patch.save("transpose.amxd", device_type="midi_effect")

Note that poly key pressure is in opposite orders. The unpack → pack pattern works because unpack sends its rightmost element first, so velocity is waiting in pack before pitch arrives and sends the pair.

Without a MaxPatch

save_amxd and load_amxd convert between a .amxd file and the patch’s JSON, for when you change the JSON yourself:

from maxpylang import save_amxd, load_amxd

data = load_amxd("sine_instrument.amxd")      # the patcher JSON as a dict
save_amxd(data, "copy.amxd", device_type="instrument")

A .amxd file written by maxpylang is the same JSON as a .maxpat, wrapped in three binary chunks: ampf (the device type: aaaa, iiii or mmmm), meta (maxpylang writes zeros), and ptch (the JSON). Devices Max saves frozen store a binary container in ptch instead, which these functions cannot read; see Known issues.
