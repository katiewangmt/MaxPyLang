Inlet

class maxpylang.Inlet(parent, index, sources=None, midpoints=None, types=None)

Class representing MaxObject Inlet.

Generic over the rate it accepts (see maxpylang.rates), for static checking only.

Keeps track of patchcords through a list of source Outlets. Also keeps track of midpoints of the cord, if any.
