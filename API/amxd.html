Max for Live (.amxd) files

Most code never calls these directly: patch.save("synth.amxd", device_type="instrument") and mp.MaxPatch(load_file="synth.amxd") use them for you. See Max for Live.

maxpylang.save_amxd(patcher_json, filename, device_type='instrument')

Wrap a patcher JSON dict in .amxd binary format and write to file.

maxpylang.load_amxd(filename)

Read an .amxd file and return the patcher JSON dict.

maxpylang.DEVICE_TYPES

The device_type values save() and save_amxd() accept, mapped to the four-byte code written into the file: "audio_effect", "midi_effect", "instrument".
