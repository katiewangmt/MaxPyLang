API reference

Generated from the docstrings in the maxpylang package. Everything below is importable from the top level, import maxpylang as mp, except the rate classes, which live in maxpylang.rates.

  • MaxPatch: a Max patcher file.

  • MaxObject: one box in a patch.

  • Inlet, Outlet: an object’s inlets and outlets.

  • save_amxd(), load_amxd(), DEVICE_TYPES: Max for Live files.

  • maxpylang.rates: what a patch cord carries, for type checkers.

  • UnknownObjectWarning, ConnectionWarning, GraphWarning and import_objs().
