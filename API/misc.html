Warnings and object data

The three warnings maxpylang raises; see Checks and warnings. ConnectionWarning and GraphWarning are importable from maxpylang; UnknownObjectWarning from maxpylang.exceptions.

class maxpylang.exceptions.UnknownObjectWarning

Raised when a Max object name is not recognized.

class maxpylang.ConnectionWarning

Raised when a patch cord sends audio into an inlet that takes no audio.

class maxpylang.GraphWarning

Raised at save for a problem in the shape of the patch: a hot loop, audio feedback with no delay, or an object whose output reaches nothing.

maxpylang.import_objs(*packages, overwrite=False, defaults='max')

Import objects from MaxMSP packages for compatibility with Python interface. Creates object template files.

Requires io files for each package describing the relationship between inlets/outlets and arguments.

Usage: input –> list of package folder names, use keyword “vanilla” as shortcut for [max, msp, jit, m4l]. overwrite –> flag to re-import previously imported objects defaults –> where each object’s default box comes from:

“max”: Max opens a patch of bare objects and saves it. Needs an authorized Max,

because an unauthorized one cannot save.

“shipped”: read from the patches Max ships (help files and examples), which Max

saved itself. Needs no running Max. An estimate: see get_shipped_obj_info for how a box is chosen and how far it agrees with a Max save.

With defaults=”max”, make sure the Max application is OPEN when running this command! If import fails, set wait_time higher and re-import.
